
# Mortgage Calculator (Java)

This project is a simple Java-based Mortgage Calculator that calculates:

- Monthly Payment Amount
- Total Interest Paid Over the Life of the Loan

It uses user input to calculate the expected monthly payment and total interest using the compounded interest formula.

---

## Features

- Accepts user input for:
  - Principal Loan Amount
  - Loan Term (Years)
  - Annual Interest Rate

- Calculates:
  - Monthly Payment
  - Total Interest Paid
